# V13 Phase 2S

Phase 2S is a structural predictive rebuild, not a portfolio fix. It was introduced because Phase 2R recovered broad pre-2025 OOF alpha but failed across all six horizons in the 2021-2022 regime while still showing meaningful future-winner lift.

The hypothesis tested is that the prior information set could identify relative winners but could not distinguish beta/style exposure from residual alpha during the inflation/rate-shock regime. Phase 2S therefore adds causal macro regime proxies and PIT factor sensitivities, then learns residual alpha and asymmetric tails.

No 2025+ observations are loaded or used.
